# Gameplay sound effects

The five Mixkit files listed below were supplied by the user on 2026-10-15 and are
unchanged. All other effects are original deterministic PCM synthesis generated by
`tools/art/rebuild_audio.mjs`; no additional audio was downloaded.

| Files | Use |
| --- | --- |
| `mixkit-crunchy-footsteps-loop-535.wav` | Continuous walking, stopped during vaults/climbing and at the destination |
| `mixkit-explosion-hit-1704.wav` | Nearby grenade, breach and other conventional explosions |
| `mixkit-epic-impact-afar-explosion-2782.wav` | Explosions more than 18 map units from the tactical camera focus |
| `mixkit-shotgun-pump-1659.wav` | Combat Shotgun cycling after a shot and on reload |
| `mixkit-handgun-click-1660.mp3` | Sidearm readying and reloading |
| `rifleShot`, `sniperShot`, `shotgunShot`, `sidearmShot`, `suppressedShot`, `flameShot` | Weapon-family reports |
| `rifleReload`, `sniperReload` | Weapon-family handling and reloads |
| `impactUnit`, `impactStone`, `impactMetal`, `impactGlass`, `impactWood` | Projectile impacts by target material |
| `doorOpen`, `doorKick` | Door interactions |
| `throwWhoosh`, `meleeHit` | Throwable release and melee contact |
| `heal`, `recover`, `extract` | Healing and objective interactions |
| `overwatch`, `contactAlert` | Reaction stance, trigger, and enemy discovery |
| `uiSelect`, `uiConfirm` | Soldier and tool selection |
| `collapse` | Structural collapse |
| `hydroBurst`, `cryoBurst`, `anemoBurst` | Non-ballistic elemental interactions |

The old Mixkit weapon clips remain mechanical handling sounds, not gunshot
substitutes. Hydro events use a water burst rather than a generic explosion. Hidden
enemies and mechanical walkers do not use human footsteps. Settings → Audio controls
the saved effects volume; zero mutes everything. Playback starts after a pointer/key
gesture and stops when leaving battle or hiding the browser tab. Simultaneous voices
are capped and pellet impacts are grouped so automatic fire cannot flood the mixer.
